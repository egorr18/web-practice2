# Практична робота №9

## Що виконано

Створено React/Vite-застосунок із комплексним Mini ToDo List:

- додавання задач;
- видалення задач;
- перемикання стану "виконано";
- фільтри `All / Active / Done`;
- компоненти `Counter`, `UserCard`, `TodoItem`;
- props, state, події та рендеринг списків із `key`;
- умовний рендеринг повідомлення, коли у фільтрі немає задач.

## Запуск

```bash
npm install
npm run dev
```

## Контрольні запитання

1. React відрізняється від звичайного JS тим, що дозволяє будувати інтерфейс із компонентів і автоматично оновлює DOM при зміні стану.
2. JSX - це розширення синтаксису JavaScript, яке дозволяє описувати UI схожою на HTML розміткою.
3. `useState` використовується для збереження та оновлення стану компонента.
4. State не можна змінювати напряму, бо React не зможе коректно відстежити зміну і повторно відрендерити компонент.
5. `key` потрібен React для стабільного визначення елементів списку під час оновлення, додавання або видалення.
