# Duikt Clicker Game

Лабораторний проєкт: багатофункціональна clicker game на **React + Vite** з модульною структурою, збереженням стану в **IndexedDB**, апгрейдами, бонусами, антибонусами, престижем та скінами.

> Обраний додатковий варіант: **Варіант A — оффлайн-дохід**.

## Функціональність

- ручний клік для отримання кредитів;
- 5 типів апгрейдів:
  - Click Power
  - Auto Clicker
  - Passive Income
  - Combo Engine
  - Critical Click
- бонуси:
  - кейс
  - колесо фортуни
  - тимчасовий бустер
- антибонуси:
  - Virus — блокує магазин і скіни
  - DDoS — блокує ручні кліки
  - Glitch — зменшує пасивний дохід
- престиж із отриманням **Duiktcoins** та глобальним множником доходу;
- система скінів зі збереженням активної теми;
- повне збереження прогресу в IndexedDB;
- оффлайн-дохід після повернення до гри;
- адаптивний інтерфейс на CSS Modules.

## Опис модулів

- `hooks/useClickerGame.js` — головна ігрова логіка.
- `hooks/useIndexedDB.js` — завантаження й збереження стану.
- `db/gameStorage.js` — робота з IndexedDB.
- `utils/constants.js` — конфігурації апгрейдів, скінів, бонусів.
- `utils/formulas.js` — усі формули доходу, престижу, таймерів.
- `features/*` — функціональні секції гри.
- `components/*` — універсальні UI-компоненти.
