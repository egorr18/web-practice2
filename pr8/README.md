# Практична робота №8

## Що виконано

Створено React/Vite-застосунок магазину товарів:

- компонент `Product`;
- передача даних через props;
- масив `products` та рендеринг через `map`;
- унікальний `key` для кожного товару;
- окремий лічильник покупок для кожної картки через `useState`;
- стилізований адаптивний інтерфейс.

## Запуск

```bash
npm install
npm run dev
```

## Контрольні запитання

1. JSX - це синтаксис, який дозволяє писати розмітку всередині JavaScript. На відміну від HTML, у JSX використовуються `className`, `{}` для вставки JS-виразів і один кореневий елемент.
2. JSX має один кореневий елемент, бо компонент повинен повернути одне значення. Для цього можна використати `div` або фрагмент `<>...</>`.
3. Props потрібні для передавання даних від батьківського компонента до дочірнього.
4. `useState` створює стан компонента і функцію для його оновлення. Після оновлення стану React повторно рендерить компонент.
5. `key` допомагає React правильно визначати, який елемент списку змінився, додався або видалився.
6. Компонентний підхід спрощує повторне використання коду, структурування інтерфейсу та підтримку проєкту.
7. Дані передаються від батьківського компонента до дочірнього через атрибути JSX, які всередині дочірнього компонента доступні як props.
